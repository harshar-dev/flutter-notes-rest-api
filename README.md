# 📒 Flutter Notes REST API

A full-stack Notes application built using **Flutter**, **Node.js**, **Express.js**, and **MongoDB** with **JWT Authentication**.

## ✨ Features

- User Authentication (Signup & Login)
- JWT-based Authorization
- Create, Read, Update & Delete Notes
- Search Notes
- User-specific Data
- Secure Token Storage
- Splash Screen with Auto Login

## 🛠 Tech Stack

- Flutter
- GetX
- Node.js
- Express.js
- MongoDB
- JWT
- bcrypt

## 🚀 Getting Started

### Backend

```bash
cd backend
npm install
npm start
```

### Flutter

```bash
cd notes_app
flutter pub get
flutter run
```
